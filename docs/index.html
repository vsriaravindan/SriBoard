02//Why this exists

[OK] Privacy by default
The app’s AndroidManifest declares NO INTERNET permission by default. AI features only enable it when the user opts in. Your keystrokes never leave the device unless you explicitly run an AI action.
[OK] Inline AI, no Accessibility Service
The AI toolbar integrates as a first-class keyboard action — works inside any input field in any app. Other AI keyboards need Accessibility Service (which can read your screen); SriBoard doesn’t.
[USER OWNS API KEYS]
API keys live in your device storage. No SaaS subscription, no telemetry, no data sent to a server. You pay providers directly. Delete the app = keys gone.
[FEATURES] v2.3 iterative shipping
Bulk dictionary import · Gboard layout mode · model quick-pick dropdown · markdown-to-plain-text pre-commit · 7 user-defined toolbar presets (Fix, Translate, +5 custom).
[FOUNDATION] HeliBoard lineage
Forked from HeliBoard / OpenBoard AOSP. Inherits glide typing, split keyboard, multilingual, clipboard history — plus the AI toolbar bolted on as a keyboard action.
